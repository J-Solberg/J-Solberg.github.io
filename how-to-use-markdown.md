# Getting started with markdown

Markdown is easy to learn. It's even simpler than HTML. Some organizations use markdown and create their docs in an environment like GitHub. 

## What you'll need

* A text editor (you can use Visual Studio Code or just work directly in GitHub)
* A sense of ~~fun~~ adventure

## To practice some simple markdown in GitHub
1. Open your GitHub account
2. Create a new file and save it as markdown-practice.md (note the .md file extension).
3. Use the Markdown cheat sheet below to create a page hat includes
  - Heading 1
  - Heading 2
  - numbered list
  - bulleted list
   - horizontal line
    - image
    - link
    - paragraph
    - emoji 
   

## To practice some simple markdown in VS Code
1. Install **VS Code**.
2. Install a free extension: **Auto-Open Markdown Preview**.
3. Create a new file and save it with a .md file extension.
4. Add a snippet of code to your documentation, like this: 
` <p>Hello world!</p> `
5. Learn more at [freeCodeCamp](https://www.freecodecamp.org/news/markdown-cheat-sheet/).
