# About [name of manual / documentation]

This project is documentation meant for content creators who want to make their content more accessible--in particular, their video content. This project was created as a collaborative multi-team project. The tools we used include MadCap Flare, GitHub (for hosting), and Google docs (for collaborative drafting and editing.)

The resulting documentation is topic based (modular) and includes a mix of mainly task topics (procedures) and concept topics.


## Goals of the project
This Flare project offers accessibility guidance for making videos accessible, with a particular focus on Microsoft's Sharepoint Stream plaform and ClipChamp editing app.
